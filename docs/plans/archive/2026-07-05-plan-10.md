# Hearsay Plan 10 — Ship-Shape Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** v1 becomes shippable: the balance harness plays thousands of campaigns and the numbers get tuned against pinned target bands; daily seeds and save/load make it a game people return to; Electron + steamworks wrap it for Steam; the controller path proves the input abstraction; performance holds at campaign scale; and the ship checklist — licenses, naming gate, version stamps — closes.

**Architecture:** Nothing new conceptually — this plan is measurement, tuning within pinned decision rules, packaging, and audits. Balance changes obey the strictest form of the house discipline: ONE lever per pass, measured before/after on the same seed batteries, re-baselined by sweep, and every target band written down BEFORE the first measurement run. Difficulty variance across seeds is embraced, bounded by the validator, never flattened (spec law) — tuning aims the DISTRIBUTION, not individual seeds.

**Tech Stack:** existing engine/app + `electron`, `electron-builder`, `steamworks.js` (devDeps, wrap-only — the browser build remains the dev truth). No engine dependencies.

## Global Constraints

- **All Plan 6–9 global constraints carry forward verbatim.**
- **Targets before measurements (pinned here, revisable only by Ellie):**
  - Competent-play win rate (canny-investigator archetype, default 40 days): **40–70%** across 200 seeds.
  - Open final door (pillar 2): **≥ 5%** of seeds winnable by day 12 by the speedrunner archetype (the door exists), and **0** seeds won by day 3 (no free lunches).
  - Loss mix: no single loss kind (`clock` / `exposed` / `caught`) exceeds **70%** of losses.
  - Soak stays **≥ 90%** first-try; suite wall time **≤ 90s**; nightly digest p95 **≤ 25 ms** at day 40.
- **Bounded lever list:** economy prices, pressure tiers, watch window, quorum, artifact cost/lead, informant coverage window, vigilance range, trait-pool weights. The juiciness table and stance thresholds move ONLY with Ellie's sign-off (they re-baseline everything). Formulas and pillar mechanics move never.
- **The sim never reads the clock:** daily seeds derive from the LOCAL DATE in app code (app is entropy-exempt by the P5 lint carve-out); the seed string enters the session like any other — replays carry it explicitly.
- **Ship gate is a checklist, not vibes:** every item below in Task 9 is checked or the tag doesn't land.
- Every task: full gate suite; balance tasks re-run soak/mc/battery and publish tables.

### Task 1: The bot fleet and the outcome battery

**Model:** opus
**Review:** opus

Spec's balance harness: "headless Monte Carlo campaigns via scripted bot archetypes; tune pacing from outcome distributions." Archetypes (each a deterministic policy over `playerView` + boards — bots play the PLAYER's information, never ground truth; the no-omniscience law applies to our own tools):

- **patient-investigator:** assign informants wide, ask/debrief toward the usurper's secret, tell only corroborated truth to council-adjacent carriers.
- **aggressive-fabricator:** forge early, courier fabrications on coronation axes, accept heat.

`runCampaignBattery({ archetype, seeds, days })` → per-seed `{ status, endDay, exposureAtEnd, coinAtEnd, turnedCouncil }` + aggregate distribution tables. Battery test prints the four archetypes × 20 seeds (env `BATTERY_SEEDS` scales to 200; positive-int guard).
