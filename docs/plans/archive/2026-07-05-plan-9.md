# Hearsay Plan 9 — Artifacts, Magic & the Debrief Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Evidence that beats hearsay and the loop that teaches: forged documents that push belief past the hearsay ceiling and leave forensic trails; scrying and séance priced like sin; period prose rendering for every claim; and the debrief — thread view, sketch timeline, counter-sketch overlay — where the curtain finally lifts on ground truth and every campaign becomes a lesson.

**Architecture:** Artifacts are WORLD OBJECTS carrying a fixed claim (documents don't mutate; interpretations do — retellings OF an artifact ride ordinary trait physics, but showing the paper re-anchors belief at evidence weight). Magic never breaks information physics: scrying is one purchased remote feed through the ONE perception path; séance is one interview with a gen-seeded departed witness — both leave traces (arcane residue is evidence; grave visits are presence). The debrief lives in `src/sim/debrief/` (zero-eslint nesting again): pure folds over the chronicle/claims/decisions substrate that Plans 1–8 have been recording all along (the spec's hard requirement — data always captured, views arrive now). Ground truth reaches the UI through EXACTLY ONE gate: the composition root passes `debriefView` only when `scenario.status` is terminal, and a test proves the gate.

**Tech Stack:** existing engine + app; no new dependencies.

## Global Constraints

- **All Plan 6–8 global constraints carry forward verbatim.**
- **The evidence hierarchy is law (spec):** artifacts/witnessed ≫ hearsay. `HEARSAY_CEILING` (0.95) caps corroborated hearsay; witnessed sits at 0.95; an artifact IN HAND anchors at `ARTIFACT_CREDENCE = 0.97` — the only credence above the ceiling, and only while the holder physically holds it. No other constant may cross the ceiling.
- **Magic is narrow, priced, and traceable:** info/communication access ONLY; no minds moved except by rumor physics; every ritual debits coin AND leaves an observable trace. Magic SPENDS deduction (you must already know where to look), never replaces it.
- **Pillar 6 holds until the curtain:** nothing debrief-shaped renders while `status === 'running'`. The debrief gate is structural (one pass-point + test), and the debrief models — which lawfully read ground truth — are never imported by panels directly (props only, computed at the gate).
- **Determinism/forensics:** artifact ids replay-stable (`a${counter}`); residue/trace entries are ordinary evidence rows; every new record kind joins the chronicle unions with default-throw discipline.
- **Escalation + reviewer licenses, jargon law, provenance law, asset-slot law: in force.**
- Every task ends with the full gate suite; content/gen tasks re-baseline with the sweep protocol.

```ts
// src/sim/artifacts.ts
export const ARTIFACT_CREDENCE = 0.97;   // the ONLY number above HEARSAY_CEILING — evidence law
export interface Artifact {
  id: string;                    // `a${world.artifactCounter}` — replay-stable
  spec: InjectSpec;              // the fixed text: documents don't mutate
  author: 'player';              // v1; enemy honeytrap artifacts are the staged v1.1 knob
  forgedTick: Tick;
  /** Exactly one of: held by an NPC/avatar, or planted at a venue awaiting pickup. */
  heldBy: EntityId | null;
  plantedAt: VenueId | null;
}
// WorldState gains: artifacts: Artifact[]; artifactCounter: number;

export interface ForgeAction { tick: Tick; kind: 'forge'; spec: InjectSpec }        // cost: economy.forgery (new: 6); 1-day lead — usable from next day
export interface PlantAction { tick: Tick; kind: 'plant'; artifact: string; venue: VenueId | null; to: EntityId | null }
// venue XOR to: leave it where someone will find it, or hand it over (hand-over = a beat-circle act, tell-shaped validation)
export interface ShowAction  { tick: Tick; kind: 'show'; artifact: string; to: EntityId }   // beat-circle act
```

**Physics (exact):** SHOW: the target ingests the artifact's spec as a fresh-family claim at `ARTIFACT_CREDENCE`, `heardFrom` = avatar, `apparentSources` = the DOCUMENT's attribution (paper is its own witness); artifact stays with the shower. HAND-OVER (`plant` with `to`): target becomes `heldBy` AND ingests as SHOW; holders RE-SHOW autonomously: a holder whose stance reaches BELIEVE shows the paper to their highest-trust edge at their next shared beat (once per holder — the letter circulates on conviction, one more store-and-forward face); each re-show re-anchors the new viewer at ARTIFACT_CREDENCE. VENUE PLANT: first NPC scheduled there at the next beat picks it up (deterministic: lexicographic among that circle) and ingests. Retellings ABOUT the letter (from viewers who no longer hold it) are ordinary hearsay — mutating, capped by the ceiling: interpretations aren't fixed. Chronicle: `ArtifactRecord { kind: 'artifact'; tick; act: 'forge' | 'plant' | 'show' | 'pickup' | 'reshow'; artifact: string; by: EntityId; to: EntityId | VenueId | null }`.
